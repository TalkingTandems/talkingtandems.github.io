TTGR03 – The Muirside Rides

Two loops from DBSC featuring two different places called “Muirside”.

Start/Finish: DBSC Shed

Quick Navigation

  • Basic Route (35 km)
  • Extended Route (60 km)
  • Notes
Basic Route
~35 km Easy

Step-by-Step Directions

  1. Start: DBSC
  2. Hillend → InverK → North Rd → Duloch → Townhill (refreshments: Loch Café) → Bowershall → Muirside (1) → Craigluscar → Crossford → Waggon Road → Charleston → Limekilns (more refreshment options) → Rosyth → Ferry Toll Rd → Inverkeithing → FCP → Dalgety Bay → Finish: DBSC
Extended Route
~60 km Moderately Difficult

Step-by-Step Directions

  1. Start: DBSC
  2. Follow the Basic Route to Bowershall, then:
  3. Knockhill X-roads → Knockhill → Hillend → East Muirhead → Shieldbank (refreshments) → Saline → Oakley → Cairneyhill → Muirside (2) → Crombie → Charleston → Limekilns → Rosyth → Ferry Toll Rd → Inverkeithing → FCP → Dalgety Bay → Finish: DBSC

Notes

  • These rides feature two different places named Muirside; the “(1)” and “(2)” labels distinguish them.
  • Refreshment options en route include Loch Café (Townhill), venues in Limekilns, and Shieldbank.
  • “FCP” refers to the Fife Coastal Path.
